# Schema dumps

Generated by `tools/pair_and_enumerate.py enumerate`. Committed artifacts:

- `cloud_device.json` — the device's `GET /devices` entry: its 23 cloud
  capabilities (commands / values) that the cloud command channel drives.
- `cloud_states.json` — raw Sony IoT cloud state snapshot for the device.
- `cloud_field_paths.json` — flattened dotted field paths → leaf value type.
- `grpc_capabilities.json` — the TV's local capability schema, as its
  `GetCapabilities` call serves it (118 paths with their types, ranges and
  values). The tests build the integration's entities from it.
- `grpc_field_paths.json` — the same schema flattened to field paths.
- `SCHEMA.md` — notes on reading the dumps.

Identifiers in the dumps (device id, unique id) are redacted.

Not committed (git-ignored): `.credentials.json`, `.pairing_state.json` — these
hold Sony Seeds OAuth tokens and gRPC session keys.
